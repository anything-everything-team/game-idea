# game-idea

**Starwright** (working title): a peaceful voxel space-exploration and ship-building sandbox. Build a spaceship block by block, walk around inside it, and fly it across a procedurally generated galaxy of blocky planets. No combat, just engineering, exploration, and curiosity.

- Platforms: Desktop and Web (separate builds from one Godot 4 codebase)
- Players: Single-player and online co-op (2–4, desktop↔web crossplay)
- Camera: First and third person

See [GAME_DESIGN.md](GAME_DESIGN.md) for the full design document and roadmap.

## Current status: M0 tech spike

A playable voxel terrain prototype: walk, jetpack, fly, and break/place blocks on a generated alien landing zone, with a debug HUD showing performance numbers. Details, controls, and benchmark instructions are in [docs/m0-tech-spike.md](docs/m0-tech-spike.md).

**Run it:** install [Godot 4.7](https://godotengine.org/download), open this folder as a project, press Play.
